# 安装包（v1.0.1）

| 文件 | 用途 | 大小 |
| --- | --- | --- |
| `NckiksMusic-Setup-1.0.1.exe` | 安装版：按向导装到本机，创建桌面/开始菜单快捷方式，可在「应用」里卸载 | 88.7 MB |
| `NckiksMusic-Portable-1.0.1.exe` | 免安装版：放任意目录双击运行，删文件即卸载 | 81.8 MB |

校验：`sha256sum -c SHA256SUMS.txt`（Windows 可用 `certutil -hashfile <文件> SHA256` 手工比对）。

主要更新（v0.9.4 → v1.0.1）：

- **任务栏缩略图控播与进度条**：Windows 任务栏悬停预览小窗内置「上一首 / 播放·暂停 / 下一首」三键（自动适配深浅任务栏），并支持任务栏播放进度显示。
- **应用内自动检查更新**：对接 `AA1IMB/Nckik-music` GitHub Releases，支持设置页一键检查、流式下载与安装更新。
- **性能与交互升级（P0 / P1 / P2）**：暂停/空闲停跑 rAF、异步原子落盘与独立进度文件、下一首静默预取、超大本地曲库（> 500 首）虚拟滚动、播停平滑淡入淡出、设置页吸顶锚点导航与自定义软件缓存保存位置。
- **歌词体验打磨**：修复空格分割歌词后首字填充条闪烁、支持点击歌词跳转与单曲 ±0.5s 偏移微调、超 3 秒空档「…」新增慢速舒缓缩放呼吸动画，并新增桌面悬浮歌词（含穿透锁定）。
- **桌面形态扩展与瘦身**：新增系统托盘与关闭到托盘选项、紧凑迷你模式（快捷键 `M`）、设置内睡眠定时、省电低动效模式，并将苹方字体转为 WOFF2 压缩（字体体积缩减 51.4%）。

说明：

- 安装包未做代码签名，Windows 可能提示「SmartScreen 已保护你的电脑」，点「更多信息 → 仍要运行」即可。
- 这两个文件从 `player/package.json`（v1.0.1）用 `npm run dist` 产出；重新打包见根目录 `README.md` 的「构建安装包」一节。
