# 安装包（v1.3.0）

| 文件 | 用途 | 大小 |
| --- | --- | --- |
| `NckiksMusic-Setup-1.3.0.exe` | 安装版：按向导装到本机，创建桌面/开始菜单快捷方式，可在「应用」里卸载 | 88.8 MB |
| `NckiksMusic-Portable-1.3.0.exe` | 免安装版：放任意目录双击运行，删文件即卸载 | 81.9 MB |

校验：`sha256sum -c SHA256SUMS.txt`（Windows 可用 `certutil -hashfile <文件> SHA256` 手工比对）。

主要更新（v1.0.1 → v1.3.0）：

- **USB 独占（WASAPI Exclusive 位完美直通）**：内置仅 `363 KB` 的轻量原生音频子进程 `nckik-audio.exe`，可在「设置 → 音频输出」一键开关；支持本地无损（FLAC / WAV / ALAC / M4A / MP3 等）与全部在线音源（网易云 / QQ 音乐 / 哔哩哔哩 / 酷狗，经主进程 `127.0.0.1` 令牌认证回环代理支持 `Range` 拖拽与 `403` 自动换链）按曲目原始采样率/位深自适应直通外接 USB DAC；绝不覆写系统/DAC 硬件主音量，100% 音量自动旁路直通，低音量平滑斜坡衰减；设备被占用或不支持时自动回退系统混音，拔掉 DAC 自动安全暂停不强切外放。
- **原生双解码缓冲无缝播放（Gapless）**：点亮「设置 → 音频输出 → 无缝播放」开关，在 USB 独占模式下自动后台预热下一首首段 PCM，同采样率/同声道曲目在同一 DMA 缓冲内零间隙拼接（适合现场专辑、概念专辑与单曲循环），同步秒出下一首封面与歌词；跨采样率自动无爆音切频。
- **统一多音源音质切换（新增 QQ 音乐 `F000` FLAC 无损）**：左下角音质切换按键统一覆盖网易云、QQ 音乐、酷狗及后续可扩展新音源；QQ 音乐支持「无损」档位优先拉取 `F000` SQ 无损 FLAC（无权限自动降级 320k / 128k 并如实提示），支持在独占与共享模式下保留进度热切档位，同时优化 QQ 音乐 `1000` 登录过期提示。
- **独占时钟与歌词顺滑同步**：采用解码输出帧计数 + `QPC` 亚周期插值 + 渲染端单调软锁相环（PLL）时钟与采样级 Seek Pre-roll 裁剪，彻底解决 USB DAC 24-bit 打包输出下歌词漂移与闪烁卡顿问题。

说明：

- 安装包未做代码签名，Windows 可能提示「SmartScreen 已保护你的电脑」，点「更多信息 → 仍要运行」即可。
- 这两个文件从 `player/package.json`（v1.3.0）用 `npm run dist` 产出；重新打包见根目录 `README.md` 的「构建安装包」一节。
